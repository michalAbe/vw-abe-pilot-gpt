# Abe Pilot Sunny + Frog Features

## Feature Flags
- TRAFFIC_LIGHTS: False by default (only logging)
- TESLA_THEME: False by default (UI visuals)
- SUNNYPILOT_LANECHANGE: False by default

## Safety
- Do not enable TRAFFIC_LIGHTS on real road without testing
- TESLA_THEME is purely visual
- Lane-change feature requires extra testing
